Third-party software bundled with WotS Multiplayer
===================================================

The "Game folder" in this download contains BepInEx, an unmodified copy of its
x64 release (version 5.4.23.6), which loads the mod into the game. These files keep
their own licenses; the MIT license in LICENSE.txt does not apply to them.
Full license texts are in the "licenses" folder.

The BepInEx files are distributed unmodified; you can replace them with the
identical official release BepInEx_win_x64_5.4.23.6 from the release page above.
The LGPL lets you replace or modify these libraries: the mod loads whatever
BepInEx 5.4.x files are in the game folder.

War on the Sea is a game by Killerfish Games. It is not included in this download,
and this mod is an unofficial fan project, not affiliated with or endorsed by
Killerfish Games. The mod changes nothing on disk in the game's own files: it
patches the game in memory while it runs.
